# 测试报告

## 测试范围

| 范围 | 工具 | 命令 |
|---|---|---|
| 后端 API | Jest + Supertest | `cd jetlag-backend && npm test` |
| 前端组件 | Vitest + Testing Library | `cd jetlag-frontend && npm test` |
| 前端构建 | Vite | `cd jetlag-frontend && npm run build` |
| 代码质量 | ESLint | `cd jetlag-backend && npm run lint`、`cd jetlag-frontend && npm run lint` |
| 部署配置 | Docker Compose | `JWT_SECRET=... docker compose -f docker-compose.cloud.yml config --quiet` |

## 后端测试用例

| 编号 | 用例 | 预期结果 |
|---|---|---|
| BE-01 | GET `/health` | 返回 `status=ok` |
| BE-02 | GET `/metrics` | 返回 Prometheus 指标 |
| BE-03 | GET `/api/v1/symptoms` | 返回症状数组 |
| BE-04 | POST `/api/v1/auth/register` | 注册成功并返回 token |
| BE-05 | POST `/api/v1/auth/login` | 登录成功并返回 token |
| BE-06 | POST `/api/v1/diagnose`，`hour=0` | 返回子时 `23:00-01:00` |
| BE-07 | GET `/api/v1/history` | 返回已保存历史 |
| BE-08 | 空诊断请求 | 返回 400 |

## 前端测试用例

| 编号 | 用例 | 预期结果 |
|---|---|---|
| FE-01 | 初始渲染采集页 | 生成按钮禁用 |
| FE-02 | 选择一个症状 | 生成按钮启用 |
| FE-03 | 点击用户手册路由 | 展示手册内容 |

## 测试结论

项目已从单纯语法检查升级为覆盖核心 API、认证、历史、监控指标与核心组件交互的自动化测试。后续可继续补充图片上传、PDF 导出、历史详情、错误状态和深色主题的端到端测试。
