# 用户手册

## 1. 注册与登录

打开系统后，可在左侧登录面板输入用户名和密码。首次使用点击“注册”，已有账号点击“登录”。登录后生成的方案会自动保存到历史记录。

## 2. 采集望诊信息

在“望诊采集”页面：

1. 选择至少一个症状，或上传至少一张图片。
2. 图片支持舌像、面相、手相。
3. 可点击选择图片，也可拖拽上传。
4. 上传后可查看缩略图，并可单独删除。
5. 可填写年龄、性别、常睡时间和起床时间。

## 3. 生成七日计划

点击“生成七日调理计划”。系统会生成：

- 主要体质方向；
- 匹配度；
- 子午流注时辰与经脉；
- 今日补救建议；
- 七日饮食、运动和作息计划；
- Qwen3-VL 图像特征说明。

## 4. 查看历史记录

登录后进入“历史记录”页面，可查看最近 50 条诊断记录，包括体质方向、匹配度和生成时间。

## 5. 导出 PDF

生成计划后点击“导出 PDF”，浏览器会下载当前报告。若未生成计划，导出按钮不可用。

## 6. 主题切换

左侧“深色/浅色”按钮可切换明暗主题，系统会在浏览器本地保存偏好。

## 7. 运维监控

部署人员可访问 `/metrics` 查看 Prometheus 指标。云服务器部署时可执行 `docker compose --profile observability --env-file .env -f docker-compose.cloud.yml up -d` 启动 Prometheus、Grafana、Loki 和 Promtail。

## 8. 常见问题

### Q: 为什么不上传图片也能生成？

系统支持症状驱动的本地规则引擎；上传图片会增强图像特征记录，但不是必需项。

### Q: 为什么提示 Qwen3-VL 未配置？

需要在后端配置 `OPEN_MODEL_BASE_URL`、`OPEN_MODEL_API_KEY` 和 `OPEN_MODEL_NAME`。未配置时系统会自动使用本地规则引擎。

### Q: 结果可以作为诊断吗？

不可以。系统仅用于毕业设计展示和日常养生参考，不能替代执业医师诊断、治疗或处方。
