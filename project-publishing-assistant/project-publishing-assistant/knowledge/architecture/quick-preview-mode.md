# 快速预览模式 Quick Preview Mode

Quick Preview Mode 通过 Cloudflare Quick Tunnel 将本地项目临时暴露到公网。

## 适合

- 本地项目临时预览
- 分享给朋友测试
- 临时给客户演示
- Demo 展示
- 短期验证
- 不需要长期在线的场景
- 不需要正式数据库迁移的场景

## 不适合

- 长期部署
- 生产环境
- 稳定自定义域名
- 正式商业访问
- 需要稳定在线保障的场景

## 重要限制

公网 URL 是临时的。终端关闭、电脑关机、本地网络中断或本地项目停止后，隧道都会失效。

请把该模式视为预览路线，不要把它当成 Public Deployment Mode 的替代方案。
