## 第二步:初赛提交(07.15 截止)

初赛需要用 TRAE 把创意做成能运行、能体验的 Demo,并提交到社区。

### 提交内容

1. **可运行的 Demo**:部署到 Hugging Face Space 或其他平台,提供在线访问链接
2. **项目展示页**:用浏览器打开 `project-showcase/project-showcase.html`,截图或录屏用于社区展示

### 部署 Demo 步骤

参考项目根目录的 `PUBLIC_RELEASE.md`,流程如下:

1. 推送代码到 GitHub 仓库(设为公开)
2. 确认 GitHub Actions 已启用,Settings → Actions → General → Workflow permissions 选择 Read and write permissions
3. 推送到 main 分支后,Actions 自动构建并推送到 GHCR
4. 在 Hugging Face 创建 Docker Space(SDK 选 Docker,端口 7860)
5. 将 `deploy/huggingface-space/` 中的文件放到 Space 仓库
6. 修改 Space 的 Dockerfile 中的镜像地址为你的 GHCR 镜像
7. 配置 Space Variables:
   - `PORT=7860`
   - `PUBLIC_API_BASE=`(留空,同源访问)
   - `OPEN_MODEL_BASE_URL=https://你的-Qwen3-VL-服务/v1`
   - `OPEN_MODEL_API_KEY=你的密钥`
   - `OPEN_MODEL_NAME=Qwen/Qwen3-VL-32B-Instruct`
   - `CORS_ORIGIN=`(留空或填 Space 地址)
8. 验证 Space 可访问,首页能打开,点击"生成七日调理计划"能得到结果

## 常见问题

**Q: 没有配置 Qwen3-VL 服务,Demo 能运行吗?**
A: 可以。后端会自动降级为纯本地规则引擎模式,仍然能生成体质方向和七日计划,只是不做图像特征提取。/health 中 `visionModelReady` 会显示 false,但基础演示功能正常。

**Q: 初赛两条晋级通道有什么区别?**
A: 初赛设专业评审通道(300 席)与抖音人气通道(50 席)两条独立晋级通道。带 #TRAE AI 创造力大赛、#vibe coding 大赏 发抖音获 5 万+曝光可参与人气通道。

**Q: 复赛需要做什么?**
A: 在初赛 Demo 基础上完善,交付一个具备完整用户路径和核心能力的正式产品。参考 `待改进.md` 中的 P1/P2 改进项,补齐功能完整性和工程质量。
