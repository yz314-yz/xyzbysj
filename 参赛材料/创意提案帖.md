## 创意名称与介绍

**创意名称**:岐养七日

**想解决什么问题**:
中医讲究"辨证施养",但普通人面对体质辨识、子午流注、饮食宜忌这些概念时往往一头雾水。市面上的养生应用要么只推送泛泛的科普文章,要么把体质测试做成娱乐问答,测完之后无从落地。用户真正需要的是:告诉我现在是什么体质方向,然后给我接下来七天每天吃什么、做什么运动、几点睡觉。

**为什么会想到做这个**:
做毕业设计时选了中医方向,查阅资料发现中医的体质辨识和子午流注理论非常成体系,但这些知识停留在古籍和专家头脑里,普通人很难直接拿来用。于是想做一套系统,把这些知识编码成规则引擎,再结合 Qwen3-VL 的图像理解能力做望诊图片的特征提取,最终输出一份可执行的七日调理计划。

**大概是什么产品**:
一个 Web 应用。用户上传舌像、面相、手相图片并选择症状,系统通过本地规则引擎和可选的 AI 图像分析,生成体质方向、当下时辰的经脉养生建议,以及一份覆盖饮食、运动、作息的七日计划,支持导出 PDF 和查看历史记录。

## 目标用户及痛点

**面向哪些用户**:
25-45 岁关注自身健康的成年人,对中医养生有兴趣但缺乏系统知识,希望通过日常调理改善疲倦、失眠、消化不良等亚健康状态。

**在什么场景下使用**:
- 身体不适时,想了解自己的体质方向并获得具体调理方案
- 日常想根据当下时辰做对应的养生(比如子时养胆经、卯时大肠经当令)
- 体检后想通过中医方式做长期调理,需要一个可跟踪、可回看的计划

**当前痛点**:
- 体质测试结果只是一段文字描述,测完没有后续行动方案
- 养生知识散落在各处,饮食、运动、作息建议互相矛盾,不知道该听谁的
- 中医术语(阴虚、气虚、子午流注)门槛高,普通人看不懂
- 线下中医咨询单次几百元,难以持续跟踪体质变化

## 价值与意义

**社会价值**:岐养七日把中医体质辨识和子午流注理论从专业领域搬到了普通人的屏幕上。用户不需要理解"阴虚火旺"是什么意思,系统会直接告诉他:今天喝银耳莲子羹,晚上 11 点前入睡,做一组八段锦。这种知识下沉让传统中医智慧真正服务于日常健康管理,降低了普通人获取专业养生指导的门槛。

**技术价值**:项目验证了"本地规则引擎 + 大模型图像理解"的混合架构在中医辅助场景的可行性。规则引擎保证结果可解释、可追溯,每次推荐都能说清楚依据;Qwen3-VL 负责望诊图片的特征提取,弥补纯规则无法分析图像的短板。整个系统容器化部署,具备完整的 CI/CD 流水线、Prometheus 监控和 Loki 日志采集,是一个工程化完整的产品而非概念验证。

## 核心功能

| 功能 | 说明 |
|------|------|
| 望诊采集 | 支持舌像、面相、手相图片上传、拖拽、预览和单张删除 |
| 智能分析 | 本地规则引擎 + 可选 Qwen3-VL 图像特征提取,双引擎协同 |
| 体质方向 | 根据症状和图片特征给出九大体质方向判断 |
| 子午流注 | 结合当前时辰推荐对应经脉的养生建议 |
| 七日计划 | 生成覆盖饮食、运动、作息的七天调理方案 |
| 历史记录 | 注册登录后可查看历次诊断结果,支持体质变化跟踪 |
| 报告导出 | 一键将七日计划导出为 PDF |
| 工程化 | Docker 部署、GitHub Actions CI/CD、非 root 容器、健康检查、限流、安全头 |

## 技术架构

```
浏览器 (React + Vite)
    │
    ▼
Express API ── JWT 鉴权 ── SQLite 持久化
    │
    ├── 本地中医规则引擎 (症状→体质→计划)
    ├── Qwen3-VL 图像特征提取 (OpenAI 兼容接口)
    ├── Swagger API 文档 (/api-docs)
    ├── Prometheus 指标 (/metrics)
    └── Winston 日志 + Loki 采集
```

前端使用 React、Vite、React Router、react-hot-toast、html2canvas、jsPDF。后端使用 Node.js、Express、SQLite、JWT、Zod、Multer、Helmet、Morgan、Winston。AI 接入通过 OpenAI 兼容接口连接 Qwen3-VL。测试覆盖 Jest + Supertest 后端接口测试和 Vitest + Testing Library 前端组件测试。

## 使用 TRAE 的开发过程

整个项目从需求分析到部署上线,全程借助 TRAE IDE 的 AI 辅助能力完成。主要环节包括:

- 需求梳理:与 AI 助手对话,从模糊的"中医养生系统"想法逐步收敛到"望诊采集 + 体质分析 + 七日计划"的具体功能边界
- 架构设计:AI 帮助拆分前后端模块结构,生成系统设计文档和接口定义

- 工程化:AI 协助配置 Docker、GitHub Actions、Swagger、Prometheus、Loki 等基础设施
- 测试与文档:AI 生成测试用例和用户手册,人工审核校验
